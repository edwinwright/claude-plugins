# obsidian-note-writer

The workflow for getting notes into and around an Obsidian vault: searching before creating, enhancing without losing content, and splitting or moving notes safely.

## When to use

- User asks for notes on a specific topic (create from scratch)
- User provides existing notes that need cleanup or restructuring
- User wants content split, merged, moved, or renamed

## Related skills

This skill deliberately owns **no** formatting or structure rules. Shape, layout, and Obsidian notation all come from **note-formats**, which is the single source of truth for them. If a convention appears in both, note-formats wins and the copy here is a bug.

Placement and naming come from the host vault's own `CLAUDE.md`, not from this skill.
